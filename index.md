## ❓ Frequently Asked Questions

### Q: Will this break my IDA Pro?
No. IDAPro-MuiLs only changes visual elements. It doesn't alter how IDA Pro processes data, executes scripts, or interacts with binaries. If you ever want to remove it, simply delete the `muiLs.py` file from the plugins folder.

### Q: Do I need to know Python?
No. The plugin is written in Python (which is a programming language), but you don't need to understand anything about Python to install or use it. Everything runs automatically.

### Q: Does it work with older versions of IDA Pro?
This plugin is specifically designed for IDA Pro 9.3. While it might work with other versions, the developer has tested and optimized it only for 9.3.

### Q: Can I undo my customizations?
Absolutely. You can reset all settings back to the plugin's defaults by going to the MuiLs menu and selecting "Reset to Defaults."

### Q: Is there any risk of data loss?
No. The plugin doesn't touch any of your files, projects, or analyses. It only changes how the interface looks.
